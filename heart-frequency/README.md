# 心动频率 · 破次元恋人创新概念

交互流程：选择颜色 → 匿名回应匹配 → 原创角色试聊 → 下载初遇卡。

## 运行

直接打开 index.html，或在此目录运行 `python -m http.server 8000` 后访问 http://localhost:8000。

纯 HTML / CSS / JavaScript，无需安装依赖。Google Fonts 不可用时自动回退系统字体。

## 演示范围

原创非官方概念原型。试聊采用预设分支，未接入生成式 AI、支付、通知或破次元恋人 App。输入不上传服务器。
